# dsh-donevoice 🔔

**DSH 的完成提醒官。** 你切去别的窗口干活时，DSH 里的任务**完成 / 等你审批 / 等你回答 / 执行失败**，
它就用 **Windows 系统通知**（屏幕右下角）+ 一声提示音叫你，**点一下就回到那个会话**。
系统级卡片 + 柔和提示音（**可自行上传音效**），点击直接回到那个会话。

> 提醒由 **DSH 宿主进程**发出，不依赖页面——你把 DSH 最小化、切到别的页面、标签被冻住，都照样能收到。

## 它提醒什么

| | 什么时候提醒 | 通知长什么样 | 提示音 |
|---|---|---|---|
| 🟢 | **任务完成** | 会话从「运行中」变回空闲 | 「任务完成」+ 会话名 + 本次耗时 | 上行提示音 |
| 🟡 | **等你审批** | 有操作在等你许可 | 「等待你的许可」+ 工具名 + 理由 | 上行提示音 |
| 🔵 | **等你回答** | Agent 提问后等你选 | 「需要你的回答」+ 第一个问题 + 问题数 | 上行提示音 |
| 🔴 | **执行失败** | 会话级错误 | 「执行失败」+ 错误摘要 | **下行**提示音（一听就知道不对） |

另外：

- 🖱 **点通知 = 回到那个会话**。DSH 没在跑就直接帮你启动它。
- ⏱ **自动消散**：默认 6 秒，带进度条；**鼠标悬停暂停计时**；可点忽略按钮；按 `Esc` 关掉最新的。
- 🔄 **不会重复响**：同一条事情有两条检测通道，宿主会自动去重，只响一次。
- 🛡 **绝不会卡住审批**：插件完全不订阅审批/提问的决策链，只读官方聚合状态。

## 什么时候弹、什么时候安静

这是插件的**定稿行为**，不是开关：

| 你的状态 | 会发生什么 |
|---|---|
| **不在 DSH 页面上**（切到别的窗口、最小化） | **一定**弹系统通知 + 响提示音。这是强制的，没有开关能关掉它 |
| **正看着 DSH** | **绝不弹系统通知**，默认连卡片和声音都没有（你在看屏幕，提醒多余）。想要页内卡片就打开唯一的可选开关「页内卡片」 |
| **刚切走的那一瞬间** | 事件发生那刻你还在页面上、但 1.8 秒内切走了 ⇒ 复核后**补发**，不会漏 |
| **子代理（subagent）** | **不提醒**（子代理会刷屏），只由主管会话提醒一次。这是写死的规则，设置页里**没有**对应开关 |

> 「你在不在 DSH 页面上」由**宿主直接问 Windows**（前台窗口属于哪个进程），所以页面卡住、被冻结、压根没开都照样准。

## 系统要求

| 要求 | 说明 |
|---|---|
| **仅 Windows 10 / 11** | 系统通知走 Windows 通知中心、音效走 WPF、点击回跳走 AUMID 快捷方式 + `donevoice://` 协议——都是 Windows 专有。**macOS / Linux 上装了不会有任何反应** |
| **DSH 桌面版 0.2.0-rc.2** | 开发与验证都在这个版本上。换别的 DSH 版本可能因接口变化而失效 |
| **无需管理员权限** | 安装只动你自己的 profile 目录；首次运行时创建的开始菜单快捷方式与协议注册都写在 `HKCU` / `%APPDATA%` |
| **无需联网** | 插件不访问任何网络，音效也随插件自带 |
| 无需 Node（可选） | 只有命令行安装脚本需要 Node ≥ 20；没装也可以用 DSH 自带的运行时，见下 |

## 安装

### 方式 A（推荐）：一行装完

1. 打开 DSH → **设置 → 插件 → 添加插件**
2. 把这行粘进去：

   ```
   github:zywnb-2/dsh-donevoice#v1.1.0
   ```

3. 确认安装 → **重启 DSH** → 打开 **设置 → 提醒 → 总开关**

> **`#` 后面那串别删。** 它是版本号，带上才能锁死一个发布版；不写会跟着 main 的最新提交跑，
> 那是「随时可能变的开发版」，出了问题和文档对不上。
> 这个入口也认**本地目录的绝对路径**（例如 `D:\AppMaker\DSH-Creation\DoneVoice\dsh-donevoice`）。

### 方式 B：命令行

```bash
dsh plugin --profile desktop add github:zywnb-2/dsh-donevoice#v1.1.0
```

profile 不叫 `desktop` 就换成你自己的（`<DSH_HOME>/profiles/` 下的目录名）。
装完同样要重启 DSH。（你的 DSH 版本不认 `add` 的话，用 `install` 代替。）

### 方式 C：离线 / 开发用脚本（可控、可预演、可回滚）

**没网、或者正在改这个插件本身**时才用。日常安装走方式 A 就行——DSH 内置的插件管理器
做的是同一件事，不用你手动碰 profile。

```powershell
cd <你放这个插件的目录>\dsh-donevoice
node install.mjs            # 预演：只打印要动哪几个文件，不写盘
node install.mjs --apply    # 确认后执行（复制到 .dsh + 备份 profile 的 package.json）
```

没装 Node 也能跑（两条都实测可用）：

```powershell
# 用 DSH 自带的 node
& "<DSH 安装目录>\resources\runtime\primary-runtime\dependencies\node\bin\node.exe" install.mjs --apply

# 或者让 DSH 主程序以 node 模式跑
$env:ELECTRON_RUN_AS_NODE = 1
& "<DSH 安装目录>\DeepSeek Harness.exe" install.mjs --apply
```

脚本只做三件事，件件可逆，且**不动 profile 自己的 `cordis.patch.yml`**：

1. **把插件复制到 `<你的 DSH home>\donevoice\plugin\`**（默认就是 `C:\Users\<你>\.dsh\donevoice\plugin\`，和从 npm / GitHub 装的其它插件一样，都在 `.dsh` 里）
2. profile 的 `package.json` 加一条 `"dsh-donevoice": "link:<上一步那份副本>"`
3. `dsh.profile.bundles` 追加 `"dsh-donevoice"`，并在 `node_modules/` 下建一条指向**副本**的链接

> **为什么是复制而不是直接指向源码目录**：插件在 profile 里是一条 junction。如果 DSH（或别的工具）卸载插件时"递归删除跟随链接"，被清空的就是 junction 指向的那个目录——**真实事故**：有人因此被删掉了整个插件源码目录。
> 复制进 `.dsh` 之后，那个"可能被连带删掉"的目录只是副本，**永远碰不到你的源码**。
>
> 只有**开发这个插件本身**时才用 `--link`：
> ```powershell
> node install.mjs --apply --link    # profile 直接指向源码目录，改一个文件即刻生效（代价：卸载可能连带删源码，请先 git 保护）
> ```
> 两种模式可以随时互相切换，脚本会自动把链接**重新指向**正确位置。

每次写盘前都会把 profile 的 `package.json` 备份成 `package.json.donevoice-backup-<时间戳>.json`（不会自动清理，可手动删）。

**装完必须重启 DSH 桌面进程**（新的插件代码要重启才会被加载）。

## 装完怎么用

1. **重启 DSH**
2. 打开 **设置 → 提醒**
3. 打开 **「总开关」** —— ⚠️ **默认是关的**，「装了没反应」九成是因为它没开
4. （可选）打开 **「页内卡片」**：这样你正看着 DSH 时也会在右下角出卡片
5. 挑一个提示音，点 **「试听」** 听一下，再按需拉音量
6. **切到别的窗口**，让 DSH 跑个任务 —— 任务结束时右下角应该弹出系统通知 + 提示音

> 第一次提醒可能**慢约 2 秒**（要拉起常驻的音效进程），之后就几乎瞬时。

## 设置项

设置页只有「功能 + 开关」，一行解释文字都没有：

| 设置项 | 默认 | 说明 |
|---|---|---|
| **总开关** | **关** | 单独一块放最前，优先级最高。**关着时下面全部变灰、不可点**。开着 ⇒ 四类提醒全都提醒 |
| **页内卡片** | **关** | **唯一的可选开关**：打开后你正看着 DSH 时也在右下角出卡片 |
| 提示音 | 铃声 | 自带音效 + 静音；可试听 |
| 音量 | 70% | 0–100；拉到 0 等于静音 |
| **音效库** | — | 点开可**导入**自己的音效，也能**逐条删除**；「自带 / 导入」有标签区分 |

设置**自动保存**，存放在 `%USERPROFILE%\.dsh\donevoice\config.json`（也可以用编辑器直接改）。改完不用点保存，切走再回来也不会丢。

> 想把卡片停留时间从默认 6 秒改成别的：编辑上面那个 `config.json` 里的 `durationSec`（允许 3–30）。

## 常见问题

**Q：装了完全没反应？**
按顺序检查四件事：① **「总开关」是不是还关着**（默认关）；② **重启过 DSH 吗**（必须重启）；③ 你是不是**正看着 DSH 窗口**——在页面上时按设计是安静的，切走再试；④ Windows 的**专注助手 / 系统通知总开关**是不是把通知压掉了（通知历史里能看到记录，说明插件发了、是系统没显示）。

**Q：为什么我盯着 DSH 的时候不弹？**
这是刻意的：你在看屏幕，提醒是多余的。想要页内卡片就打开「页内卡片」开关。而**你切走之后**的系统通知 + 音效是强制的。

**Q：点击通知没反应？**
通知横幅消失后要去 **Windows 通知中心**（`Win + N`）里点那条记录。DSH 没在跑时点它也会帮你启动并跳到对应会话。

**Q：想换提示音 / 用我自己的音效？**
设置 → 提醒 → 「音效库」→ 选择文件。支持 **MP3 / WAV / M4A / WMA / AAC**，单个 ≤ 4 MB；导入后出现在列表里，可试听、可删除。也可以把文件放进 `%USERPROFILE%\.dsh\donevoice\sounds\`（同名时优先用你的）。

**Q：会不会重复响两次？**
不会。同一件事的两条检测通道由宿主去重；而且**任何情况下 2 秒内最多响一次**。

**Q：这些提醒会不会影响 DSH 本身？**
不会。插件**完全不订阅审批/提问的决策链**，只读官方已经聚合好的状态，结构上不可能让审批卡住。

**Q：会联网吗？会不会上传我的数据？**
不会。插件只在**本机回环**上有自己的路由（配置 / 探针 / 提醒 / 试听 / 音效管理），带同源校验；不访问任何外部网络，不上传任何内容。

**Q：能装到别的盘 / 自定义 DSH_HOME 吗？**
可以。安装脚本会自己找 profile；`DSH_HOME` 环境变量优先，也可以用 `node install.mjs --profile "<你的 profile 目录>"` 显式指定。

**Q：怎么升级？**
DSH 的插件入口**没有自动更新**：在插件页卸载旧版 → 按[方式 A](#方式-a推荐一行装完)装新版（只改 `#` 后面那个版本号）→ 重启 DSH。每版改了什么见 [CHANGELOG.md](./CHANGELOG.md)。

## 已知限制

| 限制 | 原因 | 影响 |
|---|---|---|
| DSH 桌面进程整个退出后收不到提醒 | 通知由宿主进程发出 | 任何本机方案的天花板；DSH 一开就恢复 |
| 首次提醒慢约 2 秒 | 要拉起常驻音效进程 | 只影响进程起来后的第一条（之后 9–20ms） |
| 系统通知不能带按钮 | Windows 页面上下文通知不支持 | 关闭靠自动消散 / 悬停系统 ✕；页内卡片**有**忽略按钮 |
| 专注助手 / 系统通知总开关会压掉通知 | Windows 行为 | 通知历史里仍有记录 |
| 耗时是「自测值」 | DSH 不提供官方计时 | 插件自己记录"看到开始跑"的时刻 |
| 失败提醒只覆盖会话级错误 | 官方只转发会话级错误到页面 | 个别模型调用级错误可能不触发 |
| 子代理不提醒 | 会刷屏 | 硬规则，没有开关 |
| 只有 Windows 版本 | 见[系统要求](#系统要求) | macOS / Linux 不适用 |

## 隐私与数据

- **不联网**：插件不发起任何外部请求，不上传任何内容。
- **数据都在你本机**：配置在 `%USERPROFILE%\.dsh\donevoice\config.json`，导入的音效在 `%USERPROFILE%\.dsh\donevoice\sounds\`，通知图标与脚本在该目录下的 `icons/`、`worker.ps1` 等文件里。
- **只在用户范围内改动系统**：开始菜单里的一条快捷方式（通知上显示的名字与图标来自它）+ `HKCU` 下一条 `donevoice://` 协议注册。**不需要管理员权限**。
- 删掉插件目录不会在你系统里留垃圾；协议注册与快捷方式可用卸载脚本一并清理。

## 卸载

**在 DSH 里装的就用 DSH 卸**（内置插件列表里移除该插件），或者用脚本：

```powershell
node install.mjs --uninstall            # 预演：只打印要删什么
node install.mjs --uninstall --apply    # 确认后执行（同样会先备份 package.json）
```

卸载是**外科式删除**：只删本插件加的那一条依赖、那一个 bundles 项、那一个链接，不会误伤你后来装的别的插件。删完重启 DSH。
